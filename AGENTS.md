# Instruções para Codex e agentes compatíveis

Este é o repositório exclusivo do Squad de Marketing da Trinus.

Antes de qualquer demanda:

1. Leia `squad.yaml` e `ARQUITETURA-CONTEUDO.md`.
2. Carregue todos os arquivos declarados em `pensamento` e `carrega_sempre`.
3. Leia o contexto oficial da Trinus apontado por `squad.cliente`.
4. Identifique a camada, os agentes, os playbooks e os checkpoints aplicáveis.
5. Não peça novamente informações já documentadas.
6. Não conclua que o repositório está vazio com base apenas em busca, índice ou metadados. Tente os caminhos canônicos diretamente e respeite maiúsculas e minúsculas.
7. Não altere o GitHub sem autorização explícita.
8. Não versione binários. Siga `core/politica-ativos.md`.

Este arquivo é somente um adaptador. Não duplique aqui regras, memória, contexto de marca ou playbooks.
