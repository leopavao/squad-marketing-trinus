# Ciclos editoriais

Cada ciclo de conteúdo recebe uma pasta `AAAA-MM`.

Estrutura recomendada quando houver material:

- `briefing.md` — briefing aprovado do período;
- `decisoes.md` — escolhas, alterações e motivos;
- `calendario.md` — pautas e estado de produção;
- `entregas.md` — peças aprovadas, versões e links do Drive;
- `retrospectiva.md` — resultados, aprendizados e próximos ajustes.

Crie somente os arquivos necessários. Não preencha documentos vazios apenas para completar a estrutura.

O diário mensal registra a narrativa consolidada. A pasta do ciclo guarda os detalhes operacionais do período.
