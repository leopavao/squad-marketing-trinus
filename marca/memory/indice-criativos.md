# Índice de Criativos

Catálogo textual das publicações e referências armazenadas no Google Drive.

## Campos obrigatórios

- Código
- Data prevista
- Data publicada
- Tema
- Pilar
- Formato
- Canal
- Status
- Link da pasta no Drive
- Link da publicação
- Território criativo
- Motivo da aprovação ou reprovação
- Elementos a repetir
- Elementos a evitar

## Convenção de código

`TRN-AAAA-MM-DD-NN`

## Registros

Nenhuma publicação foi classificada ainda. Só adicionar uma entrada após evidência de aprovação ou confirmação humana.
