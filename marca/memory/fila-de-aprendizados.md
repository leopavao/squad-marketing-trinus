# Fila de Aprendizados

Área temporária para observações surgidas durante briefing, produção, revisão, aprovação e reprovação.

## Regra de entrada

Registrar somente aprendizados que possam alterar trabalhos futuros. Feedback pontual de texto ou gosto sem recorrência não vira regra imediatamente.

## Regra de promoção

Um aprendizado é promovido para `memoria-criativa.md` ou `decisoes-criativas.md` quando:

- for confirmado explicitamente pelo humano;
- reaparecer em mais de uma peça;
- corrigir um erro estrutural de processo;
- definir uma nova direção visual vigente.

## Pendências atuais

- Classificar as peças aprovadas anteriores quando forem recuperadas ou reenviadas.
- Identificar quais peças devem virar referências mestras.
- Registrar reprovações que tenham valor didático para futuras produções.
